WAR Model
Wins Above Replacement
A component-built WAR (batting + baserunning + fielding + positional + replacement, all in runs ÷ runs-per-win), engineered to track FanGraphs fWAR closely. Batting uses wOBA linear weights; fielding uses Statcast Fielding Run Value (Baseball Savant); pitching is FIP-based. League constants are computed live from the season. It won't equal any one source to the decimal — public WAR formulas are proprietary — but it lands within a few tenths.
